# AELADAMS
AES 408 Final Project. Automated Equilibrium Line Altitude Detection and Mapping System
AELADAMS: Automated Equilibrium Line Altitude Monitoring SystemProject Title: ELA Monitoring in Glacier Bay Using Geospatial Python Techniques   Developer: Jaelyn Longino   Project OverviewAELADAMS is an automated Python pipeline designed to identify glacier boundaries and detect the Equilibrium Line Altitude (ELA) using satellite imagery and digital elevation models. This tool transitions glacial monitoring from a manual, labor-intensive task to a scalable computational workflow.  By applying the Otsu thresholding method to Landsat 8 Near-Infrared (NIR) data, the script identifies the boundary between the accumulation and ablation zones across hundreds of glaciers simultaneously.  Key Features: Automated ELA Detection: Uses Otsu thresholding on NIR bands to differentiate snow from ice/rock.  Geospatial Masking: Integrates the Randolph Glacier Inventory (RGI 7.0) to precisely isolate individual glaciers.  Elevation Extraction: Dynamically fetches and stitches Copernicus DEM tiles to map 2D snowlines into 3D elevation data.  Large-Scale Processing: Capable of analyzing hundreds of glaciers in minutes; successfully mapped 433 glaciers in Glacier Bay in approximately 11 minutes.  Methodology: The pipeline follows a three-stage execution flow:Discovery: Queries the Microsoft Planetary Computer STAC API for Landsat 8 and Copernicus DEM data.  Segmentation: Clips imagery to RGI glacier boundaries and applies statistical thresholding to locate the snowline.  Analysis: Intersects the snowline coordinates with the DEM to calculate the mean ELA for each glacier.  Tech StackLanguage: PythonPlatforms: Microsoft Planetary ComputerCore Libraries: pystac_client, planetary_computer, geopandas, rioxarray, scikit-image, numpy, pandas, and matplotlib.Results: In its deployment in the Glacier Bay region, AELADAMS achieved the following: Analyzed 761 potential glacier polygons.  Successfully extracted valid ELA data for 433 individual glaciers.  Calculated a Regional Mean ELA of 1462.44 meters.  Generated high-resolution maps with cyan ELA outlines and exported all numerical results to a structured CSV file.
